# Учет МЦ - Система учета материальных ценностей

Веб-приложение для учета движения материальных ценностей (МЦ) с возможностью управления МОЛ, группами имущества, операциями прихода/передачи/списания.

## Требования

- Node.js 18+ 
- PostgreSQL 14+
- npm или yarn

## Установка и запуск

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка базы данных

Создайте базу данных PostgreSQL:

```sql
CREATE DATABASE mc_accounting;
```

Отредактируйте файл `.env` и укажите правильные данные для подключения:

```env
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/mc_accounting"
```

### 3. Применение миграций и seed данных

```bash
# Генерация клиента Prisma
npm run db:generate

# Применение миграций
npm run db:migrate

# Заполнение начальными данными (2 МОЛ и группы имущества)
npm run db:seed
```

### 4. Запуск приложения

```bash
# Режим разработки
npm run dev

# Или для production
npm run build
npm start
```

Приложение будет доступно по адресу: http://localhost:3000

## API Endpoints

### МОЛ
- `GET /api/mols` - Список всех МОЛ
- `POST /api/mols` - Создание нового МОЛ
- `GET /api/mols/:id` - Получение МОЛ по ID
- `PUT /api/mols/:id` - Обновление МОЛ
- `DELETE /api/mols/:id` - Удаление МОЛ

### Группы имущества
- `GET /api/groups` - Список групп
- `POST /api/groups` - Создание группы
- `GET /api/groups/:id` - Получение группы
- `PUT /api/groups/:id` - Обновление группы
- `DELETE /api/groups/:id` - Удаление группы

### Объекты МЦ
- `GET /api/assets` - Список объектов (с фильтрами)
- `POST /api/assets` - Создание объекта
- `GET /api/assets/:id` - Получение объекта
- `PUT /api/assets/:id` - Обновление объекта
- `DELETE /api/assets/:id` - Архивирование объекта

### Операции
- `GET /api/operations` - Список операций
- `POST /api/operations` - Создание операции (приход/передача/списание)
